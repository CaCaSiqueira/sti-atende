# Pacote Completo - STI Atende (SEMA-MT)

Este pacote contém os arquivos iniciais para você construir o sistema usando o **Claude Code** de forma 100% automatizada.

## Como começar:

1. **Extraia este arquivo ZIP** em uma pasta no seu computador (ex: `C:\projetos\sti-atende`).
2. Abra o terminal (Prompt de Comando, PowerShell ou Terminal do Mac/Linux) dentro dessa pasta.
3. Certifique-se de ter o Claude Code instalado. Se não tiver, rode `npm install -g @anthropic-ai/claude-code`.
4. Inicie o Claude Code digitando: `claude` no terminal.
5. Quando o Claude pedir o prompt inicial, simplesmente **copie todo o texto do arquivo `prompt_claude.md` e cole lá**.

O Claude irá ler o arquivo `index.html` (que é o nosso protótipo aprovado) e o prompt, e começará a construir a Sprint 1 (Next.js, Tailwind, etc) automaticamente para você!
